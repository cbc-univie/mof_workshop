# Welcome to my workshop on simulating metal-organic frameworks with machine learned potentials.

This workshop introduces molecular dynamics simulations using machine learned interatomic potentials (MLIPs) for adsorption in porous materials. You will set up a metal-organic framework (e.g., ZIF 8 or UiO 66) with a single CO2 or H2O molecule, run NVT simulations using a pretrained universal model (MACE MP 0b) or a domain specific MOF model (e.g., MACE MP MOFv2), and compute radial distribution functions to locate adsorption sites. Along the way, you will learn about available MLIPs, initialize stable MD simulations with ASE, visualize trajectories, and interpret RDF peaks relative to framework nodes and linker atoms. The skills are transferable: MD setup principles apply beyond MOFs to other materials and molecular systems. All examples run in Python/Jupyter with ASE, MACE, and MDAnalysis.
